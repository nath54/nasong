# Future NaSong Concepts & Examples

This directory contains **design prototypes** and **usage examples** for the upcoming NaSong features. These files are not executable yet; they serve as the **specification** for:

1.  **Music Theory Core**: How users will interact with Notes, Scales, and Chords.
2.  **NaSL (NaSong Language)**: The internal DSL for concise instrument definition.
3.  **Algo-Rave System**: How live coding sessions will be structured.
4.  **Generative Systems**: Complex, rule-based composition examples.

## Contents

*   `01_theory_basics.py`: Fundamental music theory interactions.
*   `02_instrument_dsl.py`: Designing instruments with the new piping syntax.
*   `03_live_session.py`: A mock "Algo-Rave" performance script.
*   `04_generative_systems.py`: Examples of Phase/Steve Reich style systems and Cellular Automata.
